You get one window. It is grok.com, full size, with a normal macOS title bar.

## Use the window like an app

Close it with the red traffic light. The app can stay in the Dock. Click the Dock icon to bring the window back.

There is no tab strip. There is no address bar. Links that are not Grok, xAI, Google sign-in, or Apple sign-in open in your default browser. That is on purpose.

## Pin it above other windows

Choose **View → Always on Top**, or press **⌥⌘P**. The pin in the menu is not decoration. The window will sit on top of whatever you were supposed to be doing.

Turn it off the same way.

## Find text on the page

Press **⌘F**. Type. Use Next and Previous. Close the find bar when you are done pretending you remember what you searched for.

## Zoom

**⌘+**, **⌘-**, and **⌘0** change the page size. You can also use the slider in Settings.

## Print

**File → Print…** (⌘P) prints the current page. The physical world still exists. Barely.

## Reload

**⌘R** reloads grok.com. Use it if the page looks stuck. After sign-in, the app should reload for you.
