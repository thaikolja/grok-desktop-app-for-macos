These work when Grok Desktop is in front.

| Shortcut | What it does |
| --- | --- |
| ⌘R | Reload the page |
| ⌘. | Stop loading |
| ⌘F | Find on the page |
| ⌘U | Show or hide usage stats |
| ⌥⌘P | Always on top |
| ⌘+ | Zoom in |
| ⌘- | Zoom out |
| ⌘0 | Actual size |
| ⌘P | Print |

There is no shortcut for “open 12 tabs.” That is not an oversight.
