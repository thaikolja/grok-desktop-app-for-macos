The first launch opens [https://grok.com](https://grok.com). There is no setup wizard. There is no tour. There is a window.

## Sign in on the page

Use **Sign in** on grok.com, the same way you would in Safari: xAI, Google, or Apple.

Stay in this window. If another browser pops up and looks pleased with itself, that login did not happen here. Click **← Grok** if you see it, then sign in on the page again.

After a successful sign-in, the app reloads grok.com so you actually look signed in. You should not need to press Reload yourself. If you still do, see [When things break](/help/when-things-break).

## What you will not see

- Tabs
- An address bar
- A “new window” ritual

::tip
If you leave grok.com — Google’s account picker, Apple’s sign-in, anything else — a **← Grok** bar appears at the top. It always takes you home. Use it. The internet is large and mostly unhelpful.
::
