There is no App Store listing. GitHub Actions builds every release: a universal `.app` (Apple Silicon and Intel), a disk image, and this documentation. You can also build from source if you enjoy watching progress bars.

## What you need

- A Mac running **macOS 14 Sonoma** or later (M-series or Intel)
- To build from source: **Xcode 16** or later (the full app — not only Command Line Tools)

## Download a release

GitHub Actions produces these files when a version tag is pushed. “Universal” means **one** disk image for M chips and Intel. You do not need two.

::release-download
::

::steps
### Get the disk image

Download `Grok-Desktop-<version>-universal.dmg` from [Releases](https://github.com/thaikolja/grok-desktop-app-for-macos/releases). Prefer the `.dmg`. The `.zip` is the same app if you distrust disk images on principle.

### Install

Open the disk image. Drag **Grok Desktop** onto **Applications**. Eject the disk image.

### First open

The CI build is not notarized. Control-click the app, choose **Open**, then confirm. After that, a normal double-click is enough.
::

## Open and run from source

::steps
### Open the project

Double-click `GrokDesktop.xcodeproj`. Xcode should appear. If it asks you to **Trust** the project, accept.

### Choose My Mac

At the top of the Xcode window, set the destination to **My Mac**. Phones are not invited.

### Signing

In the GrokDesktop target, under **Signing & Capabilities**, pick your Team. If you do not have a paid Apple developer membership, choose **Sign to Run Locally**. That is enough to run the app on this computer.

### Press ⌘R

Xcode builds the app and launches it. The first time can be slow. The second time is why people keep using computers.
::

## If Xcode is missing

Install Xcode 16 or later, open it once so it can finish its own setup, then try again.

Command Line Tools alone are not enough. They will argue with you in a small, unhelpful font.
