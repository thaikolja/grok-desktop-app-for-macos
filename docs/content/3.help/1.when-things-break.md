This is version **1.0.0**, the first public release. Bugs can happen.

Start with **← Grok** if you see it. Then try the matching item below. If none of this helps, [open an issue](https://github.com/thaikolja/grok-desktop-app-for-macos/issues).

## Chrome or Safari opened during Google sign-in

That login belongs to the browser, not to this app.

1. Close the browser window.
2. Click **← Grok** in Grok Desktop.
3. Sign in again on the grok.com page **in this app**.

## The page says it is finishing sign-in and never stops

Click **← Grok**, then sign in again inside the app. Do not paste Google links into another browser. Those links expire, usually at the worst time.

## Sign-in worked but the page still looks logged out

Press **⌘R**. Version 1.0.0 reloads grok.com after a successful sign-in. If you still see the old screen, reload once more, then quit and reopen the app.

## Google shows an error 400

The sign-in request was cut off or finished in the wrong place. **← Grok**, then start over in Grok Desktop. Do not reuse an old Google consent link.

## “Anderes Konto verwenden” or Back does nothing on Google’s page

Use **← Grok** to leave. Sign in again from grok.com. You are not required to win a fight with Google’s account picker.

## The app will not build

- You need **Xcode 16+**, not only Command Line Tools.
- Destination must be **My Mac**.
- Signing can be **Sign to Run Locally**.

If `xcodebuild` complains about the developer directory, install full Xcode and point it at that app, not at Command Line Tools.

## Microphone or camera never starts

Grant access in **System Settings → Privacy & Security** for Grok Desktop. The app only allows those for grok.com.
