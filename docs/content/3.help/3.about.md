**Grok Desktop** version **1.0.0** is a native macOS app by **Kolja Nolte**.

It opens grok.com in WebKit. It is not a browser. It is not Electron. It is not an xAI product, partnership, or cry for attention directed at xAI.

This is the first public release. Things can break. Use **← Grok**, reload, or quit and reopen, then [tell me](https://github.com/thaikolja/grok-desktop-app-for-macos/issues).

Source: [thaikolja/grok-desktop-app-for-macos](https://github.com/thaikolja/grok-desktop-app-for-macos)
